# OpenHarness 源码分析笔记

> 基于 [OpenHarness](https://github.com/open-harness/open-harness)（Claude Code 风格的开源 AI 编程助手，Python 实现）的源码精读。
> 核心代码 4 万多行，本套文档逐模块拆解其架构设计与实现细节。

**一句话总结**：模型只负责"思考"，OpenHarness 提供模型之外的一切——工具、记忆、权限、沙箱、多渠道接入、多 Agent 协作。

## 我的产品 —— SnapByFace

SnapByFace 是一款离线优先的桌面端人脸搜索与整理工具，支持 macOS 与 Windows。

- **本地 AI 识别**：基于 ONNX Runtime 的人脸检测与特征提取，所有计算在本地完成，照片不离开设备
- **以图搜图**：导入一张参考人脸，即可在数万张照片中找出同一人的所有照片
- **视频支持**：不仅支持图片，还支持从视频文件中提取帧进行人脸识别
- **隐私优先**：无云端依赖，无账号体系，数据完全存储在本地 SQLite 数据库
- **多语言**：支持中文 / 英文双语界面

官网：https://snapbyface.com/
